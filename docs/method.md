# 口径与执行规则

## 时点语义

以信号日 T 在交易日历中的序号为基准：

```
买入日 = T + entry_offset          默认 entry_offset = 1
卖出日 = 买入日 + hold_days         默认 hold_days = 2 → T+3
```

`hold_days=H` 的含义是**买入日到卖出日之间正好跨 H 个交易日**。默认口径
（H=2、开盘买、收盘卖）即：T 日收盘后出信号 → T+1 开盘买 → T+3 收盘卖。

`entry_offset` 强制 ≥1。T 日信号在 T 日成交属于前视，构造 `ExecConfig` 时直接报错。

买入价与卖出价各自可选：

| 取值 | 复权列 | 说明 |
|---|---|---|
| `open` | `adj_open` | 开盘集合竞价 |
| `close` | `adj_close` | 收盘集合竞价 |
| `vwap` | `adj_vwap` | 全天成交量加权均价 |

成交与损益一律用**复权价**；涨跌停判断用**原始价**（涨跌停价本身是原始价口径）。
估值用 ffill 后的复权收盘价——停牌日沿用最近有效价，成交价则从不 ffill。

## 执行规则

与 HistQuantOpt 的 `RealisticBacktester` / `ExecutionLedger` 同口径，两边净值可比。

| 情形 | 处理 |
|---|---|
| 买入日成交价涨停（`raw ≥ limit_up × 99.9%`） | 放弃该票，资金留在现金 |
| 买入日停牌（`trade_status == "停牌"`） | 放弃该票 |
| 买入日无行情（未上市 / 已退市 / 代码错误） | 放弃该票，计入 `no_quote` |
| 卖出日成交价跌停（`raw ≤ limit_down × 100.1%`） | 顺延到下一可交易日，`side=sell_deferred` |
| 卖出日停牌 | 顺延 |
| 退市（面板中该票整行消失，价格与 `trade_status` 同时缺失） | 不论是否到期，当日按最近有效收盘价强制核销、扣卖出费，`side=sell_delist` |
| 费率 | 非对称：买入 `cost_buy` 默认 1‰，卖出 `cost_sell` 默认 2‰（含印花税） |

**停牌不等于退市**：停牌日面板中仍有该票的行（`trade_status="停牌"`），走顺延；
只有价格与交易状态**同时**缺失才判定退市。这条区分由
`tests/test_execution_rules.py::test_suspension_is_not_treated_as_delisting` 守住。

`trade_status` 共 5 种取值（交易 / 停牌 / XD / XR / N），其中 XD（除息）、XR（除权）、
N（新股首日）都可正常交易，因此不可成交的判定只写 `== "停牌"`，绝不写 `!= "交易"`。

## 资金分桶与资金利用率

每日建仓预算 = `前收盘总资产 / 桶数`，桶内逐票等权。

### 桶数为什么不等于 H

一笔钱从买入时点占用到卖出时点。若**卖出时点晚于买入时点**（如开盘买、收盘卖），
卖出当日的回款赶不上当日开盘的建仓，这笔钱要跨 **H+1** 个建仓时点，
所以桶数自动取 H+1；只有当卖出时点不晚于买入时点（开盘买+开盘卖、收盘买+收盘卖）
时，回款当日即可复用，桶数才等于 H。

强行按 1/H 分桶（`n_buckets=H`）会在启动阶段错位一次，之后永久欠一桶资金，
退化成周期性的**建仓不足**——桶照建，但金额远低于目标。这比彻底跳过更隐蔽，
所以 `exec_stats` 单独报 `underfunded_buy_days` 与 `avg_funding_gap`。

### 结构性现金闲置

改桶数**不会**降低平均现金占比。开盘买、收盘卖的口径下，永远有一桶回款在途，
现金占比的物理下限就是 `1/(H+1)`，`exec_stats.structural_cash_pct` 直接报这个值。
H+1 换来的是每日预算稳定、不出现「跳过一天 → 次日现金翻倍」的震荡。

要真正吃掉这部分闲置，只能把卖出时点提前到不晚于买入时点：

| 口径（H=2） | 桶数 | 结构闲置 | 实测平均现金占比 |
|---|---|---|---|
| T+1 开盘买、T+3 收盘卖 | 3 | 1/3 | 38.9% |
| T+1 开盘买、T+3 开盘卖 | 2 | 0 | 9.8% |

（实测值取 2024-01-01 ~ 2025-12-31 的涨停信号样本，日均 70 只。）

`vwap` 是全天均价、不对应单一时点，无法保证卖在买前，一律保守地按「先买后卖」处理。

## 前视自查

- 信号日 T 的选股只能用 ≤T 的数据；成交日 ≥ T+1 由 `entry_offset ≥ 1` 强制。
- 内置信号生成器（`limit-up` / `random`）只读 T 日截面，不含未来信息。
- 引擎逐日推进，第 i 日只访问 `frames` 的第 i 行及更早行；退市核销用的
  「最近有效价」来自 ffill 后的历史价，不含未来价。
- 自有信号接入前，建议用 `look-ahead-detector` 复核构建代码。

## 随机基线

`hqpick signal random` 在同一套执行口径下生成随机选股。任何策略的净值都必须
显著跑赢它，否则「超额」只是执行规则或市场 beta 带来的假象。用法见操作指南。
