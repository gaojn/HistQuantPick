## 验收线

2026-08-18 提出：**Sharpe > 1 且年化收益 > 20%**（真实成交口径，含费率、涨跌停、T+1 约束）。

## 方法论（比任何一条结论都重要）

1. **候选清单先定死，不边跑边调参**。跑之前把要试的变体列全，跑完只看结果、不回头加新变体——
   否则等价于对同一份数据做无限次假设检验，总能凑出一个"看起来好"的组合。
2. **必须有匹配日程的随机基线**。每条随机路径必须复用策略的信号日期、每日选股数和
   执行参数（同 H、同 N、同资金模式）；用多路径分布而非单次 seed 判断策略是否显著跑赢，
   否则"超额"只是执行口径或市场 beta 的错觉。
   - 反例教训见下方"反转族第一轮"：H=5 每日调仓时，连纯随机基线的年化都是 **-11.6%**（IS）——
     不是选股问题，是换手成本吃掉了收益，不跑基线根本发现不了。
3. **IS / OOS 双区间验证，结论以两边同时成立为准**。样本内达标、样本外不复现，
   大概率是过拟合，不能采信。
   - 反例见"下影线 + 市值过滤"：样本内把 H=1 拉到与基线打平，OOS 没有复现（仍落后 3.2pct）。
4. **IS 与 OOS 方向反转是过拟合/行情依赖的指纹**，不是"运气不好换了个区间"。
   见"低频反转族"的 `smallcap`：IS -13.9%、OOS +20.6%——这不是发现了 alpha，
   是撞上了 2023 年后的微盘股行情，纯 beta。
5. **换手成本地板要先算，再决定要不要跑**：

   ```
   年周转次数 ≈ 242 / hold_days       （每份资金一年内完整买卖循环的次数）
   成本拖累   ≈ 年周转次数 × (cost_buy + cost_sell) × 资金利用率
             ≈ (242 / H) × 0.3% × 利用率
   ```

   H=5、利用率 77% 时成本拖累约 11%/年；H=20 时降到约 2.7%/年。**日频调仓（H 个位数）
   在当前费率下几乎不可能覆盖成本**，候选设计前先过一遍这个数，别跑了才发现是送钱。
6. **多重检验要计数**。本文件累计已试 **19 个候选**（不含探索性冒烟），
   任何时候出现一两个"两区间都还行"的结果，先假设是抽样噪音，除非有独立的经济逻辑支撑。

## 逐个结论

### 1. 连续 2 板涨停（第 1、2 天涨停 → 第 3 天开盘买 → 第 4 天收盘卖）

- **区间**：2017-01-01 ~ 2026-07-16（缓存上限），默认口径 H=1/N=2/slots
- **结果**：年化 -61.4%，最大回撤 **99.99%**（近乎清零），Sharpe -1.88；
  10 个自然年份**全部为负**；同口径随机基线 -24.0%
- **逐笔**：14,248 笔，胜率 41.3%，盈亏比 0.97，期望值 -1.63%/笔，
  盈亏平衡胜率需 50.9%（胜率和盈亏比两个维度同时不利）
- **根因**：25%（10,343/41,221）的信号因 T+1 一字涨停买不进。买到的都是没封住的弱票，
  构成系统性逆向选择——回测证明的不是"打板无效"，而是"按开盘价买涨停股只能买到最差那批"
- **结论**：❌ 证伪。若要继续验证打板类策略，必须先解决"涨停价挂单撮合"的执行口径，
  当前引擎（涨停只有"放弃"一种处理）无法回答这个问题

### 2. 下影线放量（+ 流通市值过滤）

- **逻辑**：长下影线代表盘中砸盘后被买回、有承接；叠加放量避免选到流动性插针
- **样本内**（2024-2025）：12 个口径配置全部跑输基线 10~29pct
- **加市值≥50亿过滤后**：H=1 在样本内把差距从 -11.5 拉到接近打平（+0.2）
- **样本外验证**（2020-2023，同一份市值过滤逻辑）：**没有复现**，H=1 差距回到 -3.2、
  H=2 差距 -10.5
- **结论**：❌ 证伪，且是典型的**样本内二次调参过拟合**——市值过滤是看着 2024-2025
  的结果加上去的，不是先验假设，OOS 检验直接把它戳穿

### 3. 短期反转族（第一轮，H=5 每日调仓）

- **逻辑**：A 股散户占比高，个股短期超跌后有均值回复
- **7 个变体**（裸反转、流动性过滤、20日动量过滤、低波动过滤、大市值过滤、
  单日反转、放量过滤）全部为负，**且全部跑输随机基线**
- **关键发现**：连**随机基线本身**在 IS 期间都是 -11.6%——不是选股问题，
  是 H=5 每日调仓的换手成本（年化约 48 次往返 × 0.3% ≈ 14.5%）远超任何量价因子能提供的 alpha
- **结论**：❌ 结构性问题，方案设计错误（H 定得太短），不是因子本身无效。促成了第二轮

### 4. 低频反转/质量因子族（第二轮，每 5 日调仓、持有 20 日、4 批重叠）

- **改动**：把年周转从 48 次压到 12 次（成本拖累 14.5%→3.6%），随机基线随之从
  IS -11.6%/OOS -3.8% 转为 IS -4.8%/OOS +11.4%——基线终于是干净的参照系
- **8 个候选**（20日反转、60日低波动、60日动量、小市值、低换手、及三种叠加流动性/波动的变体）：
  - `mom60`（60日动量）两区间一致为负——A 股动量效应方向相反，符合 A 股"追涨杀跌反噬"的经验认知
  - `lowturn`（低换手）两区间收益均为正，但**跑输基线**（OOS -1.9%）——赚的是市场 beta
    不是选股 alpha
  - `smallcap`（小市值）IS -13.9%、OOS +20.6%——方向完全反转，是 2023 年后微盘股行情的
    单边押注，不是稳定因子
  - 其余候选均为负或不稳定
- **结论**：❌ 8 个候选无一通过"两区间同时跑赢基线"的检验

## 关键方法论沉淀（比策略结论更有复用价值）

1. **成本地板必须先算**：见上方公式。任何持有期 H 个位数的日频策略，
   在 3‰ 往返费率下先亏掉 10%+ 的年化基数，这是在看任何因子之前就该排除的方案
2. **随机基线不是可选项，是强制项**：没有它，会把"市场本身在跌、策略跌得比市场少"
   误判成"跑赢大盘"（`连续2板` 若不看基线会得出"跌 61% 好像还行"的荒谬结论）
3. **样本内过滤条件 = 二次调参**：任何"加个条件就打平了"的改进，没有 OOS 验证前一律不采信
4. **`no_free_slot_days` 决定仓位可比性**：N 偏小会导致大量信号被丢弃，此时不同配置的
   仓位不可比，比较前必须先核对这个数字（详见 `docs/method.md#n-与-h-解耦`）
5. **IS/OOS 方向反转是明确的过拟合/行情依赖信号**，不需要更多样本去"确认"，直接淘汰

## 尚未尝试、可能更有希望的方向

1. **多因子合成路线**（HistQuantScreen → HistQuantCombo/FM → HistQuantOpt）：
   单因子截面 IR 上限约 0.3~0.8（A 股经验），结构上很难单独做到 Sharpe > 1。
   多因子合成 + 组合优化 + 行业风格中性是这个目标现实的路径，HistQuantPick 的定位
   是执行真实性复核而非因子挖掘，见 `README.md` 的仓库分工图
2. **引入财务数据**：本仓库缓存只有量价与基础属性字段，价值/质量类因子在 A 股是
   相对稳健的 alpha 源，但需要 HistQuantScreen/Factor 侧的财务数据支持，Pick 本身没有
3. **更早的历史区间做最终 holdout**：本文件所有实验用了 2017-2026 的绝大部分历史，
   2012-2016 目前完全没碰过，留作任何后续候选的最终验证，不要提前用掉
4. **`hqpick/signals/reversal.py`**：反转族因子的实现代码已保留在仓库中（未接入 CLI，
   属研究模块），供后续在低频结构下尝试新的因子组合时复用因子计算逻辑
   （`load_reversal_factors` / `select_top`），不必重写
